Help Center

How do I send money?
Go to the Send Money page, enter the recipient's mobile number, amount, and PIN, then confirm the transaction.
How do I cash out?
Open Cash Out, enter the agent number, amount, and your PIN to complete the request.
How can I view transaction history?
Open the Transaction History page from the dashboard to view all your recent activities.

About Tranzo

Tranzo is a Smart Mobile Financial Transaction System developed as an academic project.

Version: 1.0

Frontend: HTML, Tailwind CSS, DaisyUI, JavaScript

Backend: API Integration (Future)
